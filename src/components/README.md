# SpineGuard Presentation & Visualization Components (`src/components/`)

## What
This directory contains modular, highly reusable React UI components that render the biomechanical visualizer, interactive scenario controls, data source switcher, developer telemetry inspector, guided calibration modal, system observability widgets, and navigation headers.

## Why
To deliver an engineering-grade IoT experience for interviewers and users alike, UI components are decoupled from raw sensor acquisition and business logic. Each component focuses strictly on presentation and user interaction, consuming normalized telemetry events emitted by the unified `PosturePipeline`.

## How
The components in this directory interact as follows:
- **`SpineVisualizer.jsx`**: Dynamically calculates sagittal and lateral vertebral curvature across 10 anatomical spinal nodes (cervical, thoracic, lumbar) using SVG cubic Bézier arcs. Updates colors, glow filters, and vertebra stress nodes in real-time based on `PostureState` (`GOOD`, `WARNING`, `BAD`).
- **`DataSourceSelector.jsx`**: Provides a clear and honest data origin toggle (`Live Hardware` vs `Simulation Mode`), ensuring transparency regarding whether sensor data is being polled from serial hardware or generated by the kinematic engine.
- **`ScenarioRunner.jsx`**: Provides scenario execution controls (Healthy Sitting, Gradual Slouch, Severe Slouch, Forward Lean, Recovery, Long Session) with play, pause, step progress, and reset mechanisms.
- **`RawTelemetryInspector.jsx`**: A collapsible technical view providing live streaming tabular inspection of raw 6-DOF IMU vectors (`ax`, `ay`, `az`, `gx`, `gy`, `gz`), feature vectors, and copyable JSON telemetry payloads.
- **`SystemStatusWidget.jsx`**: Displays genuine, measured operational parameters: data ingestion frequency (Hz), total packets processed, active reference datum, session uptime, and audio synthesizer state.
- **`CalibrationModal.jsx`**: Interactive 3-step baseline orientation workflow that guides the user through posture stabilization, captures gravity vector samples, computes mean reference spinal angle, and saves calibration thresholds.
- **`HardwareArchitectureViewer.jsx`**: Technical schematic showing the 6-layer architecture from MPU-6050 I2C registers to the Next.js presentation layer.
- **`HardwareVideoDemo.jsx`**: Verification showcase with step-by-step test protocol walkthrough and responsive video demonstration container.
- **`Navbar.jsx` & `ProfileDropdown.jsx`**: Responsive navigation bar with scroll-aware visibility and user session controls.

## Overall Summary
`src/components/` translates raw kinematic signals into visually intuitive, responsive, and scientifically honest user interfaces, enabling comprehensive evaluation of SpineGuard's IoT pipeline without physical sensor dependencies.
